# 💧 Water Monitoring System

## 👥 Team: Purelytics

## 📌 About

This project is an Arduino-based water monitoring system that checks water quality using sensors and shows real-time data.

---

## ⚙️ What it does

* Measures pH, TDS, turbidity and temperature
* Shows values on LCD
* Sends data to Blynk app
* Gives alert when water is unsafe

---

## 🛠️ Components Used

* ESP32
* pH Sensor
* TDS Sensor
* Turbidity Sensor
* DS18B20 Temperature Sensor
* 16x2 LCD

---

## 💻 Code

This repository contains the Arduino (.ino) code for reading sensors and displaying/sending data.

---

## 🚀 How to use

1. Open the code in Arduino IDE
2. Install required libraries
3. Select ESP32 board
4. Upload the code
5. Check output on LCD or Blynk
